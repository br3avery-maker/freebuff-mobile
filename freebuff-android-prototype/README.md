# Freebuff Mobile · 概念原型(HTML)

为 Freebuff 官方开源仓库(`CodebuffAI/freebuff`)规划的**安卓手机 App 概念原型**。
纯静态、零依赖:一个 `index.html` + 原生 CSS/JS,浏览器直接打开即可预览;
多文件子资源请用附带的极简静态服务(见下)。

## 运行

```bash
# 任意静态服务器皆可,仓库自带一个:
node dev-server.js 4187
# 打开 http://127.0.0.1:4187/index.html
```

桌面宽度下会自动以 393px 手机视口居中展示(手机宽度下全屏自适应)。

## 结构

```
index.html            骨架:状态栏 / 屏幕容器 / 底部导航 / 弹层根
css/app.css           设计变量(深/浅主题)+ 全部组件样式
js/app.js             文案数据层 STR + 模型目录 + 会话数据 + 交互逻辑
assets/logo-icon.png  官方品牌标(白底终端图标)
docs/proposal.md      给官方仓库的提案说明
docs/custom-model-spec.md  自定义模型字段与 URL 规范化规范(原生工程参考)
```

设计基准取自官方品牌:深色 zinc 底、lime 强调、终端白标;字体为 Inter / JetBrains Mono 风格栈。

## 发起任务(底部「+」)

点底部「+」不再直接建空对话,而是进入**三步向导**:代码仓库 → 选择模型 → 任务描述,最后「发起任务」把任务投放到对话页:

1. **代码仓库** —— 三个来源:不关联仓库(仅凭描述工作)、手动输入 git 地址(协议自动补全 https://、SSH 原样保留,带完整性校验与规范化预览;输入框下带 GitHub / GitLab / Gitee 常用平台快捷粘贴,自动带出主机与协议补全提示;**粘贴整条 git clone 命令或带分支深链(#/tree)时自动解析 owner/repo 与分支**(如 `git clone -b dev https://…/r.git` → 填入仓库并显示「分支 dev」胶囊;支持 `ssh://git@host:port/…`、GitLab 子组、Gitee/私有域名与 `#`/`/tree/` 深链解析))、Git 账号仓库(连接后从账号读取,演示数据 octocat/hello-world 等;未连接时提供「去连接」直达集成页)。
2. **选择模型** —— 分类列表:**官方模型在上**,自定义模型在下(无自定义时显示空态引导)。
3. **任务描述** —— 概览卡(仓库/模型)+ 多行描述(必填校验)。

发起后:新会话以任务描述为首条消息,气泡上方带 **仓库/模型 上下文芯片**;Agent 以携带仓库与模型信息的模拟回复流式输出;任务所选模型同时成为当前模型。中途关闭向导会**保留草稿**,下次打开继续。

## 版本检查与更新(设置 → 关于 → 版本)

版本行点击「检查最新版本」(演示):发现新版本 v0.2.0 时展示版本对比与更新内容,「同意并更新」后模拟下载进度 → 安装 → 重启应用;更新后版本号持久化为最新版,再次检查提示「已是最新版本」。

## 集成(设置 → 集成)

- **Git 账号**:演示 GitHub OAuth 授权。连接后状态行变为 `@octocat`,可查看授权范围并二次确认断开。所有请求为仿真,不产生真实网络调用。
- **自定义模型**:完整的添加/编辑表单 —— 基本信息(显示名称 + 实时徽标预览、模型 ID)、能力(上下文长度 8K–524K、请求超时)、端点(**Base URL**:输入框下实时预览完整请求路径;缺少协议时自动补全 https://(失焦写回输入框);可直接粘贴中转站完整地址——以 /chat/completions 结尾则原样使用,否则自动拼接;API Key 带显示/隐藏、TLS 证书校验开关)、**高级选项**(自定义请求头,可折叠)。**测试连接**:模拟请求预览的完整路径,成功后从 /v1/models 拉取模型列表,点选即填入「模型 ID」(空名称时自动生成显示名);拉取快照随模型保存,再次编辑时直接展示「上次可用模型」卡片(标题栏带「从快照重建」按钮,一键填入快照首个模型 ID);列表元信息行以徽标显示「上次可用 N 个模型」——**点击徽标即展开快照面板**,可直接浏览并点选快照里的模型 ID(切换本端点的模型),无需进入编辑表单;面板底部带「**重新测试连接**」,就地重连该端点并刷新快照(保持展开);每个模型行旁有**可点选状态点**——点击即单独测试该模型(模拟延迟),测试后状态点变绿并就地显示「上次连通时间 · 延迟」,批量重测会为全部模型生成连通记录并随模型持久化。加载存档若检测到损坏记录,列表顶部会显示「已自动修复 N 条异常记录」提示条(可展开逐条明细并关闭),修复结果自动回写存档;提示条可展开为**完整报告**(统计「原始 N 条 → 保留 N 条」+ 逐条明细),并支持**一键恢复原始记录**:点击后先弹出**二次确认与差异对比**——逐条列出「原始 vs 已修复」的字段差异(ID/名称/模型 ID/Base URL/API Key 脱敏/上下文/超时/请求头/TLS/模型快照),已丢弃的非对象记录单独标注,确认后才执行恢复(仅本次会话生效,不写回存档)。列表项展示完整元信息(含快照数量徽标),第三行统一显示为完整请求路径,**每行可编辑**(预填表单)或删除(二次确认);加载时会清洗损坏的旧记录,杜绝脏数据导致列表/表单打不开;保存后出现在「选择模型」的自定义模型分组,被删除的当前模型自动回退官方默认。数据(连接态/自定义模型)持久化于本机 `localStorage`。

## 约定

- 界面中文文案集中于 `js/app.js` 的 `STR` 数据层,便于后续本地化。
- 所有对话均为预置演示,**不连接真实模型**;集成相关授权亦为演示仿真。
- 主题、模型、自定义模型与 Git 连接态仅存本机。
